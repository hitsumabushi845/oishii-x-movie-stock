# 動画ライブラリの整理と性能改善

目的: 動画を探して開く操作を読みやすくし、入力・切り替え時の不要な処理と復旧不能な状態を減らす。

既存構成: Vite / TypeScript / Fuse.js、Python / httpx / Pydantic。297件、4アカウント。データ形式と GitHub Pages 配信を維持する。

## 設計

白 #ffffff、背景 #f3f6fa、文字 #243248、補助文字 #58677d、区切り #dbe3ed、淡いブルー #e9f0fa。ダークモードでは同じ情報階層を青みのある面で表現する。グループ色は識別用に使用。外部Webフォントをなくし、端末の日本語ゴシックとシステム書体で軽く読みやすくする。

PCでは左にグループ選択とサイト説明、右にグループ見出し・検索・投稿一覧。スマートフォンではグループ選択を上に配置。投稿本文は2行まで、日付と尺を補助情報として見せる。総尺の巨大表示、尺メーター、行ごとの登場アニメーションを廃止。写真のないデータに架空のサムネイルは足さない。

候補として「現在のレイアウトの微調整」「音楽誌風の強い装飾」も検討したが、今回は動画を探す用途とユーザーのデザイン改善依頼に合わせて、情報階層から再構成する。

## 実装と検証

- [x] `archive.ts`: グループ取得Promiseの共有と失敗時の破棄。日付順・統計は取得時に一度だけ計算。検索ライブラリは検索時に読み込み、同じクエリの結果を再利用。実データを使った処理時間比較と検索・フィルタ・順序のテスト。
- [x] `main.ts` / `url-state.ts`: URL状態を分離、150msの入力待ちと日本語変換対応。リクエスト世代番号で古い成功・失敗を無視。ページ全体を壊さず再試行可能にする。検索・履歴・切り替え競合の統合テスト。
- [x] `render.ts` / `embed.ts`: 同じ投稿DOMを再利用。遅延埋め込みは失敗時に再試行可能、閉じた投稿には描画しない。表示中の読み込み状態・Xへのリンクを用意。埋め込み失敗と再試行のテスト。
- [x] `index.html` / `styles.css` / `groups.ts`: 上記のUIへ変更、キーボードフォーカス、選択状態、空結果、読み込み、モバイル対応。PC・スマートフォン・明暗の実画面検証。
- [x] Python: JSON文字列の往復と本文全体の日時置換を廃止。比較時のモデル辞書化を削減。循環カーソルを例外で停止して部分データを書かない。クエリのアカウントに対応する投稿URLを生成。本文保持・ページ循環・複数グループの回帰テスト。
- [x] 全Web/Pythonテスト、本番ビルド、データスキーマ検証、差分レビュー。READMEと調査結果に実測値・残る制約を記録。
